# 🚗 AutoWash – Car Washing & Detailing Website

A responsive, multi-section landing page for a car washing and detailing business, built with **HTML5** and **CSS3** only (no JavaScript, no frameworks).

## 📌 Overview

AutoWash is a static front-end template that presents a car wash business: its services, pricing plans, locations, team, client testimonials and blog. It is a good starting point for anyone learning layout techniques with Flexbox and Grid, or for a small business needing a quick template.

## ✨ Features

- **Top bar** with opening hours, phone number and email
- **Navigation bar** with an appointment button
- **Hero section** with a call-to-action
- **About section** with a checklist of services
- **Services grid** (8 cards with icons)
- **Statistics counters** (service points, workers, clients, projects)
- **Pricing plans** – Basic, Premium and Complex cleaning
- **Washing points / locations** with a request form
- **Team section** with social media icons
- **Testimonials** section
- **Blog / latest news** cards
- **Footer** with contact info, popular links, useful links and newsletter signup
- Fully **responsive** layout (mobile, tablet, desktop)

## 🛠️ Built With

| Technology | Purpose |

## 🚀 Getting Started

### Prerequisites
Just a modern web browser. No installation or build step required.

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/akashnpatil2005/autowash.git
   ```
2. **Open the project folder**
   ```bash
   cd autowash
   ```
3. **Open `index.html`** in your browser (double-click it, or use the *Live Server* extension in VS Code).

> **Note:** An internet connection is needed for the Font Awesome icons, which are loaded from a CDN.

## 📱 Responsive Design

The layout adapts using CSS media queries:

| Device | Breakpoint |
|--------|-----------|
| Mobile | Default styles |
| Tablet | `min-width: 768px` |
| Desktop | `min-width: 1024px` |

## 🎨 Customization

- **Content:** Edit the text, prices, addresses and contact details directly in `index.html`.
- **Images:** Replace the files in `img/` and `assets/` with your own (keep the same file names, or update the paths).
- **Colors and fonts:** Adjust the values in `index.css`.
- **Icons:** Browse and swap icons from the [Font Awesome library](https://fontawesome.com/icons).
